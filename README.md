# Parkinson's Disease Data Analysis

This project is designed to analyze Parkinson's disease data from a CSV file and generate visualizations.

## Project Structure

- `main.py`: The entry point of the application.
- `read_data.py`: Contains functions for reading data from CSV and generating graphs.
- `app_widgets.py`: (Likely) contains UI components for the application.
- `constants.py`: Project-wide constants.
- `test.py`: Unit tests for the data reading functionality.
- `parkinsons data.csv`: The dataset used by the application.

## Getting Started

To run the main analysis, execute:
```bash
python3 main.py
```

To run the tests, execute:
```bash
python3 -m unittest test.py
```
